# Store Rating System

**View Demo:** https://store-rating-five.vercel.app

A full-stack Store Rating Web Application where users can rate stores, store owners can manage their stores, and admins can monitor the platform.  

---

## 🚀 Deployment
- **Frontend:** Vercel  
- **Backend:** Render

## ✨ Features

### 👤 User
- Register and login
- Browse stores
- Add and update ratings
- View average ratings

### 🏪 Store Owner
- Create and manage stores
- View store ratings and performance

### 🛠 Admin
- Manage users and stores
- Sort and monitor store ratings
- Platform-level oversight

---

## 🔐 Authentication & Authorization
- JWT-based authentication
- Role-based access control (`ADMIN`, `STORE_OWNER`, `USER`)
- Protected frontend and backend routes
